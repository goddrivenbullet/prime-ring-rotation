# Prime Ring Rotation

**v3 (root):** rings are great circles through an axis tilted T° off the polar axis (toward +x), then swept azimuth A° clockwise. Passes T=0..179 × A=0..359 = 64,800 rings. Primes in band [360g, 360g+359] become dots.
